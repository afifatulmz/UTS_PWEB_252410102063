## WEB ORBITRA
adalah web yang digunakan untuk assistant laboratorium astronomi. Web ini menggunakan template bawaan laravel yaitu blade, lalu menggunakan laravel 13. MVC diterapkan di web ini, lalu data di yabel tidak menggunakan database.
